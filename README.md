# برق‌یار | BarghYar Ultimate

نسخه PWA فروشگاهی تخصصی لوازم برق با حسابداری، انبار، فروش، خرید، مشتری، چک، قرض و تعمیرات.

## اجرا
فایل‌ها را در ریشه Repository قرار دهید و GitHub Pages را فعال کنید.

## امکانات فعلی
- مشتریان با کد ملی، تماس، آدرس، توضیحات و قیمت همکاری
- درصد همکاری قابل استفاده برای محاسبه خودکار فروش
- کالا و دسته‌بندی/مشخصات؛ مناسب لامپ‌های وات‌دار، سیم و کابل متری، فیوز، کلید و پریز و...
- ورود/خروج انبار
- خرید از فروشنده
- فروش و فاکتور
- سود و گزارش نموداری
- قرض و بدهی/طلب
- چک و اعلان نزدیک سررسید
- تعمیرات لوازم برقی
- جستجو
- حالت روز/شب
- قفل محلی
- ثبت زمان عملیات
- پشتیبان‌گیری JSON و بازیابی
- PWA و کارکرد آفلاین پایه

## نکته
Google Login و Cloud Sync نیازمند اتصال یک پروژه Firebase یا Supabase و تنظیم OAuth است. این نسخه ساختار محلی کامل را دارد و می‌تواند بدون آن نیز کار کند.
